## 1. Kemampuan Akhir yang Direncanakan (Sub-CPMK)
Mahasiswa mampu menjelaskan definisi sistem operasi, fungsi sistem operasi sebagai manajer sumber daya (*resource manager*), dan mengidentifikasi berbagai jenis sumber daya komputasi.

## 2. Kriteria & Indikator Penilaian
- **Kriteria:** Ketepatan konsep, kelengkapan identifikasi sumber daya, dan kemampuan mengaitkan fungsi OS dengan pengelolaan sistem.
- **Indikator:**
  1. Menjelaskan peran ganda OS sebagai *Extended Machine* dan *Resource Manager*.
  2. Mengidentifikasi sumber daya CPU, RAM, *storage*, dan perangkat I/O.
  3. Membedakan konsep *Time Multiplexing* dan *Space Multiplexing*.
  4. Menyiapkan lingkungan praktikum Linux (VirtualBox/WSL2/Native).

## 3. Pengalaman Belajar Mahasiswa
Mempelajari kontrak perkuliahan dan RPS; berdiskusi mengenai peran OS sebagai manajer sumber daya; menganalisis studi kasus *memory leak*; serta menyiapkan mesin virtual Linux untuk kebutuhan praktikum semester ini.
