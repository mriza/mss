## 1. Kemampuan Akhir yang Direncanakan (Sub-CPMK)
Mahasiswa mampu mengelola sistem file dan menganalisis struktur penyimpanan.

## 2. Kriteria & Indikator Penilaian
- **Kriteria:** Ketepatan memahami file/direktori, *path*, operasi file, alokasi ruang (*Contiguous, Linked, Indexed*), dan penggunaan kapasitas disk.
- **Indikator:**
  1. Menjelaskan atribut file, operasi dasar sistem file, dan struktur direktori *tree-structured*.
  2. Membedakan *Absolute Path* dan *Relative Path*.
  3. Membandingkan metode alokasi blok disk (*Contiguous*, *Linked*, dan *Indexed / i-node*).
  4. Menggunakan perintah `pwd`, `cd`, `ls`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `df -h`, dan `du -sh` pada terminal Linux.

## 3. Pengalaman Belajar Mahasiswa
Praktik navigasi direktori Linux; membuat, memindahkan, dan menghapus file/direktori; serta memantau kapasitas *storage* dengan `df` dan `du`.
