## 1. Rincian Tugas
Selesaikan seluruh latihan dan pertanyaan evaluasi pada [`Praktikum.md`](./Praktikum.md) untuk *Reference String*:
`7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2, 1, 2, 0, 1, 7, 0, 1`
1. **Latihan A — FIFO (3 Frames):** Tabel perubahan isi 3 *frame* di setiap langkah (20 referensi) dan total jumlah *Page Fault*.
2. **Latihan B — LRU (3 Frames):** Tabel perubahan isi 3 *frame* di setiap langkah dan total jumlah *Page Fault*.
3. **Latihan C — Optimal (3 Frames):** Tabel perubahan isi 3 *frame* di setiap langkah dan total jumlah *Page Fault*.
4. **Pertanyaan Evaluasi (No. 1–3):**
   - Perbandingan algoritma terbaik vs terburuk pada studi kasus di atas.
   - Analisis mengapa Algoritma Optimal tidak dapat diimplementasikan langsung pada OS nyata.
   - Pengujian ulang algoritma FIFO dengan **4 Frames** dan analisis kaitannya dengan *Belady's Anomaly*.
